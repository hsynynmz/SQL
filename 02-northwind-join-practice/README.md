# Northwind JOIN Practice

A short SQL practice set focused on understanding how table relationships change query results.

## Questions Covered

- List customers and their matching orders with `INNER JOIN`
- List all customers and matching orders, including customers with no orders, with `LEFT JOIN`

## Main Learning Point

`INNER JOIN` keeps only matching records from both tables.

`LEFT JOIN` keeps every record from the left table and returns `NULL` values for unmatched columns from the right table.
